## Selected open-source work

### [ScrapeStudio](https://github.com/pouya-fr00/ScrapeStudio)

A bilingual web studio for exploring and extracting structured data from supported public static pages. It combines a React interface, a guarded Cloudflare Worker fetch gateway, browser-side analysis, editable recipes, and local exports. It does not access private pages or provide unrestricted crawling.

[Try the playground](https://scrapestudio.pages.dev/en/playground/products) · [View the source](https://github.com/pouya-fr00/ScrapeStudio)

### [ProjectForge](https://github.com/pouya-fr00/projectforge)

A local TypeScript CLI for generating modular web projects from a starter and adding features such as authentication and comments. Its [v0.1.0 GitHub release](https://github.com/pouya-fr00/projectforge/releases/tag/v0.1.0) includes a standalone package; it is not published on npm.
